# Pitline brand files

**These are stand-ins.** They were drawn from the written description of the Pitline logo kit (DECISIONS D23), not from the official artwork. When the official vector files arrive, replace the SVGs here, then run `design/tools/build_brand.py` again to regenerate the PNGs, the icons and the copies in the app. The kit image can be kept in `C:\Users\temit\pitline-brand\` for reference. It is not in the repo.

Generated by `design/tools/build_brand.py`. It needs Python with fonttools, brotli, shapely and uharfbuzz, and ImageMagick. Text is drawn as outlines from Inter ExtraBold (`superadmin/static/fonts/inter.woff2`), so the files never depend on installed fonts.

## The mark

A bold, rounded capital A in Electric Blue. A wrench head is cut out of the right leg above the crossbar, and a Signal Orange triangle sits in the lower counter. The wordmark "Pitline" is set in Inter ExtraBold, in Navy.

## Variants

| File | What | Where it's used |
| --- | --- | --- |
| `pitline-logo-primary.svg` | Mark and wordmark side by side, in colour | Marketing header, emails (`pitline-logo-email.png`), the social card |
| `pitline-logo-stacked.svg` | Mark above the wordmark, in colour | Spare |
| `pitline-logo-mono.svg`, `-mono-stacked.svg` | All Navy, for light backgrounds | Garage admin (`/app`), sign-in, onboarding |
| `pitline-logo-reversed.svg`, `-reversed-stacked.svg` | White, keeping the orange triangle, for Navy backgrounds | Super admin (stacked), platform header, marketing footer, booking confirmation's "Powered by" |
| `pitline-icon.svg`, `-icon-mono.svg`, `-icon-reversed.svg` | The mark alone | Super admin sidebar when collapsed (reversed) |
| `pitline-app-icon.svg` (+ 192/512 PNG, `apple-touch-icon.png`) | White mark on an Electric Blue rounded square | Web manifest, Apple touch icon |
| `pitline-app-icon-dark.svg` (+ 512 PNG) | White mark and orange triangle on a Navy rounded square | Where a dark icon is needed |
| `pitline-favicon.svg`, `favicon-16/32.png`, `favicon.ico` | The colour mark on white | Favicons (`src/app/icon.svg`, `src/app/favicon.ico`, super admin) |
| `pitline-og.svg` / `.png` | 1200×630 social card: logo, "Your garage, fully booked." and the subline | Marketing page `og:image` |

In the app, `src/components/brand/pitline-logo.tsx` draws the same artwork inline, from `src/components/brand/logo-geometry.ts`, which the script generates. Copies are served from `public/brand/` and `superadmin/static/brand/`.

Clear space: leave at least the height of the A on every side. The files are trimmed to the artwork, so the clear space goes around them.

## Palette

| Name | Hex | Use |
| --- | --- | --- |
| Navy | `#0F2747` | Primary brand, headings, dark surfaces |
| Electric Blue | `#2563EB` | Primary action, links |
| Signal Orange | `#F97316` | Main call to action, highlights, focus on Navy |
| Signal Orange 600 | `#EA580C` | Focus rings on light surfaces (3.6:1; `#F97316` on white is 2.8:1) |
| Steel Gray | `#64748B` | Borders, icons, UI. Secondary text uses slate-600 `#475569`, since Steel Gray on Light Gray is 3.9:1 |
| Light Gray | `#E2E8F0` | Surfaces, borders |
| White | `#FFFFFF` | Page background |

Text on Signal Orange is Navy (5.4:1). White on orange fails AA for normal-size text.
